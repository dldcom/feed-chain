# 먹이그물 탐험대

23명의 학생이 생물 역할을 맡아 먹고 먹히는 관계를 경험하고, 실제 플레이 기록으로 먹이그물을 만드는 수업용 실시간 웹게임이다.

## 현재 구현된 흐름

```text
대기실 → 역할 공개 → 교사 모드 선택
→ 먹이사슬 1·2 또는 먹이그물 3·4 진행
→ 모드 결과(개체수 변화·관계·랭킹)

기존 1·2판 먹이그물과 실험 A/B 흐름도 호환된다.
```

핵심 규칙은 서버에서 판정한다.

- 최대 학생 23명과 교사 1명
- 6자리 수업 코드 입장
- 생물 역할 자동 배정
- 실시간 이동과 안전한 재접속
- Colyseus 0.18 고정 30Hz 입력·로컬 예측·서버 재조정·원격 100ms 보간
- 올바른 먹이 관계 발견 점수
- 바라보는 방향의 중립 타깃 표시와 서버 전방 부채꼴 먹기 판정
- 잘못된 먹이 공격 시 2초간 이동·행동 정지
- 먹기·스킬 원형 쿨타임과 먹기·배탈·방어·리스폰 이펙트/진동
- 먹히면 개체수 1 감소, 남은 개체가 있으면 3초 후 리스폰, 0이면 10초 유령 후 개체수 1로 리스폰
- 네 가지 게임 모드와 모드 2 개구리 NPC의 먹기·번식
- 플레이어·식물·NPC 개체수 배지와 모드별 결과 그래프·랭킹
- 배고픔 0에서 이동속도 30% 감소
- 4,800×3,000 규모의 4구역 맵과 단계별 중앙 축소
- 종별 기본속도 차이를 좁힌 추격 밸런스와 애벌레 몸 말기 후 탈출 시간
- 생물별 이동·도주·방어 스킬
- 3분·4분 시점의 벽 방식 맵 축소
- 식물 NPC 재생
- 실험 A의 굶주림 사망과 NPC 번식
- 개체별 빨간 관계선과 종별 파란 관계선
- 먹이그물 PNG와 전체 수업 JSON 기록 저장
- 교사용 먹기 성공률·잡힌 횟수·평균 생존 시간 기록
- 동일 시드의 생태계 A/B 비교
- 생태계 변화 그래프의 생물별 색상 범례
- 16비트 픽셀아트 HUD·월드와 10종 생물/식물 스프라이트 아틀라스

구체적인 제품 범위와 설계 원칙은 [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md)를 참고한다.

## 실행 환경

- Node.js 22.12 이상
- npm 10 이상
- 최신 Chromium 계열 브라우저
- 학생 태블릿은 가로 화면 권장

## 설치 및 개발 실행

```bash
npm install
npm run dev
```

- 학생·교사 웹: `http://localhost:5173`
- 실시간 서버: `ws://localhost:2567`
- 서버 상태: `http://localhost:2567/health`

같은 와이파이의 태블릿에서는 개발 PC의 IP와 `5173` 포트로 접속한다. 클라이언트는 접속한 호스트의 `2567` 포트를 실시간 서버 주소로 사용한다.

배포 환경에서 서버 주소가 다르면 다음 환경 변수를 지정한다.

```text
VITE_SERVER_URL=wss://game-server.example.com
```

## 주요 명령

```bash
npm run build
npm test
npm run test:multiplayer
npm run test:e2e
```

- `build`: shared → server → client production build
- `test`: 먹이 관계, 점수, 시뮬레이션 단위 테스트
- `test:multiplayer`: 23명 동시 입장·이동·먹기·유령·배탈·스킬 서버 판정
- `node scripts/smoke-modes.mjs`: 네 모드 시작·종료·제거 종·개구리 NPC 스모크 검사(서버 실행 필요)
- `test:e2e`: 데스크톱·태블릿의 교사/학생 전체 수업 흐름

Playwright 브라우저가 없다면 한 번 설치한다.

```bash
npx playwright install chromium
```

## 폴더

```text
apps/client       React + Phaser 학생·교사 클라이언트
apps/server       Colyseus 권위 서버
packages/shared   먹이 관계, 역할, 점수, 월드, 시뮬레이션 규칙
tests/rules       순수 규칙 테스트
tests/e2e         브라우저 수업 흐름 테스트
scripts           23인 멀티플레이 검사
artifacts         검증 스크린샷
```

## 디자인 작업 순서

현재 UI는 16비트 픽셀아트 기반의 숲 탐험 게임 화면이다. 일반 웹페이지형 학생 화면은 사용하지 않는다. 팔레트와 에셋 확장 규칙은 [PIXEL_ART_GUIDE.md](./PIXEL_ART_GUIDE.md)를 참고한다.
